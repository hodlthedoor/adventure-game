# Festival of the First Rain

An original PureBasic text adventure for Windows and macOS. Follow the empty village well into an underground kingdom preparing a long-delayed celebration.

Development happens on `feat/festival`. Build outputs are local and ignored.

On this Mac, set `PUREBASIC_HOME=/Applications/PureBasic.app/Contents/Resources` when invoking its `compilers/pbcompiler`. Tests compile from `tests/run_tests.pb` with `--console --output build/adventure-tests`; run `build/adventure-tests all`.
